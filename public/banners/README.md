# Bannières des pages Acheteur

Déposez ici les images qui remplaceront la bannière (dégradé bleu) en haut des pages **Par directions** et **Par secteur d'activité**.

## Règles

- **Nom du fichier** = slug de la page (minuscules, sans espace).
- **Formats acceptés** : `.jpg`, `.jpeg`, `.png`, `.webp`.

## Par directions (directions métiers)

Dossier : `banners/directions/`

| Slug (nom du fichier) | Page |
|----------------------|------|
| `achats` | Achats |
| `finance` | Finance |
| `marketing` | Marketing |
| `direction` | Direction |
| `rh` | RH |
| `it` | IT / DSI |
| `juridique` | Juridique |
| `operations` | Opérations |

Exemple : pour la page Achats, déposez `achats.jpg` (ou `achats.png`) dans `banners/directions/`.

## Par secteur d'activité

Dossier : `banners/secteurs/`

Quelques slugs : `education`, `technologie`, `industrie`, `commerce-retail`, `secteur-public`, `services-professionnels`, `immobilier`, `btp-construction`, `finance`, `sante`, `telecoms`, `tourisme-hotellerie`, `logistique-supply-chain`, `medias-communication`, `industrie-agroalimentaire`, `energie-utilities`.

Exemple : pour la page Technologie, déposez `technologie.jpg` dans `banners/secteurs/`.

Si aucun fichier n’est présent pour une page, la bannière par défaut (dégradé) s’affiche.
